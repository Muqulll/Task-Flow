# Task-Flow 📝

A lightweight, fast, and responsive task management application built with Django and Django REST Framework. Designed to keep your workflow simple today, with a local-first, Markdown-driven future in mind.

---

## 🌟 Current Features (v1.1)

- **Task Management:** Effortlessly create, view, toggle completion, and delete tasks.
- **User Authentication:** Secure user registration, session login, and logout powered by DRF endpoints.
- **Branded Password Reset:** Responsive dark-themed HTML email password reset flow with custom token verification.
- **Minimalist UI:** Clean, distraction-free dark interface built for speed.
- **Fast Local Runtime:** Lightweight SQLite backend optimized for local productivity.

---

## 🚀 Product Roadmap

- [x] **v1.0 — Django Web Engine** 
  - Core web-based task manager running on localhost.
- [x] **v1.1 — REST API & Custom Auth Engine** 
  - Django REST Framework endpoints, session authentication, and styled HTML email password reset flow.
- [ ] **v2.0 — Local Markdown (`.md`) Integration** 
  - Store and sync tasks directly in local `.md` files using YAML frontmatter.
  - Native integration with **Obsidian** vaults for two-way task syncing.
- [ ] **v3.0 — Standalone Desktop App** 
  - Package the application into a native standalone executable (`.exe`).

---

## 🛠️ Tech Stack

- **Backend:** Python 3, Django, Django REST Framework (DRF)
- **Database:** SQLite
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Tooling:** PyInstaller, Inno Setup
