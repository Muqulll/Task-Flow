# Task-Flow 📝

A lightweight, fast, and responsive task management application built with Django. Designed to keep your workflow simple today, with a local-first, Markdown-driven future in mind.

---

## 🌟 Current Features (v1.0)

- **Task Management:** Effortlessly create, view, complete, and delete tasks.
- **Minimalist UI:** Clean, distraction-free interface built for speed.
- **Fast Local Runtime:** Lightweight SQLite backend optimized for local productivity.

---

## 🚀 Product Roadmap

- [x] **v1.0 — Django Web Engine** 
  - Core web-based task manager running on localhost.
- [ ] **v2.0 — Local Markdown (`.md`) Integration** 
  - Store and sync tasks directly in local `.md` files using YAML frontmatter.
  - Native integration with **Obsidian** vaults for two-way task syncing.
- [ ] **v3.0 — Standalone Desktop App** 
  - Package the app into a native desktop `.exe` using `pywebview` and WebView2.

---

## 🛠️ Tech Stack

- **Backend:** Python 3, Django
- **Database:** SQLite
- **Frontend:** HTML5, CSS3, JavaScript
